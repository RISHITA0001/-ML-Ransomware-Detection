# RansomGuard ML – Research Paper

## Overview
This research paper presents a machine learning-based ransomware detection framework designed specifically for healthcare networks. The study focuses on behavioral analysis to detect zero-day and advanced ransomware attacks.

## Key Contributions
- Behavioral feature-based ransomware detection
- Comparative analysis of Random Forest, SVM, and ANN
- Focus on healthcare cybersecurity challenges
- Emphasis on real-time detection and low false positives

## Methodology
The system uses:
- File entropy
- File modification rate
- Process activity
- CPU and network behavior

Machine learning models used:
- Random Forest
- Support Vector Machine (SVM)
- Artificial Neural Networks (ANN)

## Results
- Random Forest achieved highest accuracy
- Reduced false positives
- Effective detection of unknown threats

## Future Scope
- Real-time ML deployment
- Integration with SIEM systems
- Explainable AI (XAI)
